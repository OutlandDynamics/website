Install ODIN

Two short guides: one if someone invited you to their server, one if you want to run your own.

ODIN is in private beta. The app comes through Apple's TestFlight or a Google Play test link, and the server is not a public download yet. During the beta, your host or Outland Dynamics will give you what you need.

I was invited to someone's server

You need your phone, the email address the invitation was sent to, and about 15 minutes. You don't set up a server and you don't make an account with us.

  1. Install the ODIN app

    During the beta, the person who invited you sends a link for the app. On iPhone it opens in Apple's TestFlight app; on Android it is a Google Play test link. ODIN needs iOS 17 or later, or Android 7.0 or later.

  2. Install Tailscale, if your host asks you to

    Tailscale is a free app from another company that privately connects your phone to your host's server when you're not on their Wi-Fi. Install it from the App Store or Google Play, sign in with your own account, and accept the share link your host sent. Leave it switched on whenever you use ODIN.

  3. Open the invitation

    Tap the link in the invitation message. It opens ODIN and fills in the server for you. If tapping does nothing, which is common in email apps, copy the link, open ODIN, paste it into the invitation box on the first screen and tap Continue.

  4. Sign up

    ODIN checks that it has reached the server that invited you. Then enter your first name, the email the invitation was sent to, and a password of at least 10 characters. You'll see the libraries that were shared with you.

An invitation works once and lasts 7 days. If it has expired, ask your host for a new one. If ODIN says the server's fingerprint does not match, stop and tell your host.

I'm setting up my own server

The ODIN server runs on hardware you own and stays at home with your files. Setting it up takes some comfort with a NAS or a home computer: you'll edit one settings file and run one or two commands.

What you need

  • A machine that is always on, on your home network: a NAS or a Linux computer that runs Docker and Docker Compose. 2 GB of memory is enough for browsing and playing files as they are; converting video needs more processor power.
  • Your media folders on that machine or its shares. ODIN reads them and never changes, moves or deletes your files.
  • A fixed address for the machine on your home network (a DHCP reservation in your router), because your phones remember it.
  • A phone with the ODIN app on the same Wi-Fi, and a computer with a web browser for the first-run page.

What has been tried so far. The beta server is built for Linux on Intel/AMD and 64-bit ARM processors. Windows is not supported as a server during the beta. Our written steps cover QNAP, Synology, Unraid and plain Linux, but not all of them have been run on real hardware yet; we'll help you through anything that doesn't match.

  1. Get the server package

    The server is not publicly downloadable yet. During the beta, your host or Outland Dynamics will give you the server package: a Docker Compose file, a settings file, and access to the server software. Contact us if you'd like to take part.

  2. Fill in the settings file

    Put both files in a folder of their own, not inside a media folder, and name the settings file .env. Open it in a text editor and fill in at least: a long random database password (letters and digits only), the path to your media folder, and the server's address on your network, which looks like https://192.168.1.20:8788. Keep this file private: it holds your passwords.

  3. Start the server

    On a NAS, install its container app first (Container Station on QNAP, Container Manager on Synology). Then, in the folder with the two files, run:

    docker compose up -d

    Within a minute or two the server and its database are running. Your media is attached read-only.

  4. Pair your phone

    On a computer on the same network, open http://<server address>:8789 in a browser, for example http://192.168.1.20:8789. The page shows a short code that changes every 10 minutes. In the ODIN app, tap Setting up your own server?, choose your server, type the code and tap Connect. Your phone is now the server's owner, and the page never shows a code again.

    On iPhone, finding the server on Wi-Fi isn't built yet: choose Enter address manually and type the server's address instead. Keep the setup page to yourself until you have paired.

  5. Add your libraries

    In the app, open the side menu and choose Libraries, then Add library. Pick the type (movies, TV, comics, music, ebooks or audiobooks), browse to the folder on the server, give it a name and tap Scan now. Removing a library later only forgets ODIN's records; it never touches your files.

    TV shows and books get their details without any setup. For movie plots, cast and posters, add a free key of your own from OMDb to the settings file; without one, ODIN shows the posters already in your folders.

  6. Invite your people

    In the app, open Sharing, choose Invite someone, enter their email and pick the libraries they may see. If you've added your mailbox's sending details to the settings file, ODIN emails the invitation from your own mailbox; otherwise use Share the link and send it by text or chat. Everyone gets their own account, progress and ratings, and sees only what you shared.

Never forward ODIN's ports (8788 and 8789) on your router, and never turn on UPnP for them. ODIN is built to answer your home network only. To use it away from home, follow the next section.

Using ODIN away from home

Out of the box, ODIN only answers phones on your home network. To watch from anywhere, use Tailscale, a separate service with a free personal plan (check its current limits before you rely on it). It makes a private, encrypted link between your server and each phone. Nothing is opened on your router, and ODIN still isn't reachable from the public internet. Your media never passes through Outland Dynamics.

  1. Install Tailscale on the server machine

    On QNAP and Synology it's in the NAS's app store; on Linux, follow Tailscale's own instructions. Sign in, note the machine's Tailscale address (it starts with 100.), and turn off key expiry for it in Tailscale's admin console so it doesn't drop off every few months.

  2. Turn on remote access in ODIN

    In the settings file, set these two lines with your own address, then run docker compose up -d again:

    UMP_REMOTE=tailscale
UMP_PUBLIC_URL=https://100.101.102.103:8788

    The second line is the address put into invitations, so invited people can reach the server from anywhere.

  3. Connect your own phone

    Install Tailscale on the phone and sign in with the same account. In ODIN, connect to the server's 100. address. The app may ask you to confirm the server's fingerprint and pair again for the new address.

  4. Share only the server with family

    In Tailscale's admin console, share just the server machine with each person rather than inviting them into your whole network. They install Tailscale, sign in with their own account, accept the share, and then open your ODIN invitation as usual.

Backups

A backup is one file holding ODIN's database (libraries, accounts, progress, ratings, playlists) and the server's identity, so phones stay paired after a restore. Your media isn't part of it, because ODIN never writes there.

  • Take one now: docker exec odin-server odin backup
  • Every night: set a time in the settings file, for example UMP_BACKUP_SCHEDULE=03:30, and start the server again. ODIN keeps the newest 7 of each kind.
  • Before every update that changes the database, the server takes a safety backup by itself. If that backup fails, it doesn't update and your data is unchanged.
  • Copy backups off the machine regularly, to another computer or a USB disk. A backup on the same disk doesn't survive that disk failing.

Backups contain the server's private key and password hashes. Keep them somewhere private, never in a media folder, and keep your own copy of the settings file too.

Updating the server

During the beta, your host or Outland Dynamics will tell you when a new version is ready and how to get it. With access to the server software, an update is two commands in the folder with your settings file:

docker compose pull
docker compose up -d

Your libraries, accounts, progress and settings stay. The server updates its own database when it starts, and your phones stay paired.

Stuck?

In the app, owners can open Server health from the side menu to see disk space, the database, backups and each library's last scan, with what to do about anything amber or red. Report a problem in About ODIN prepares a report without passwords or emails. Or write to us through Support.
